Remainder is modeled as exiting at the move amount itself (your eventual stop/trail point), same as every unfilled tier — so for a single fixed move size, tiers can only match or trail the no-tiers line. Their real payoff shows up across the sweep: on scenarios that reverse before a tier level, that tier still locked in a better price than riding the whole size down.
